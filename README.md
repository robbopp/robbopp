  ## About Me

  I work on embedded Linux BSPs for ARM boards: kernels, bootloaders and Yocto. I also freelance as a software engineer, building web and iOS apps for small businesses.

  On the embedded side I like the low-level problems: bringing up a board, porting it to a newer kernel, and working out why a device won't boot. On the freelance side I build complete products, from backend to web and mobile.
